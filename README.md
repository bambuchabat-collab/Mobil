# Экономика распива

Веб-калькулятор юнит-экономики для продажи парфюмерии на распив: считает,
что останется в кармане, если разлить дорогой флакон на пробники 2 / 5 / 10 мл.

Открывается двойным кликом по `index.html` — одна страница, без сборки,
зависимостей и бэкенда. Введённые параметры сохраняются в браузере.

## Что считает

- **Себестоимость миллилитра** с учётом доставки и потерь при разливе.
- **Полная себестоимость пробника** каждого размера: жидкость, атомайзер,
  расходники, труд, упаковка и реклама в пересчёте на штуку.
- **Минимальная цена** — точка нуля с учётом комиссий площадки, эквайринга,
  налога с выручки и возвратов.
- **Ценовая сетка** — цена при наценке ×1,5 / ×1,75 / ×2 / ×2,5 и при целевой
  марже 35%. Клик по цене подставляет её в расчёт.
- **Флакон в разрезе** — как объём делится между размерами и на каком проценте
  объёма флакон полностью отбивается.
- **Сценарии по скорости продаж** — срок распродажи, прибыль в месяц и годовой
  возврат с учётом оборачиваемости.
- **Чувствительность** — что будет при росте закупки, падении цен, удвоении
  возвратов и неполной распродаже флакона.
- **Распив против продажи флакона целиком** и итоговый вердикт с разбором
  слабых мест.

## Модель расчёта

```
полезный объём      = объём × (1 − потери)
себестоимость 1 мл  = (закупка + доставка) ÷ полезный объём
себестоимость шт    = жидкость + атомайзер + расходники + труд
                      + (упаковка + реклама) ÷ пробников в заказе
прибыль шт          = цена × (1 − комиссии − эквайринг − налог) × (1 − возвраты)
                      − себестоимость шт
вклад в окупаемость = прибыль шт + стоимость жидкости
штук до нуля        = стоимость флакона ÷ средний вклад
годовой возврат     = возврат за флакон × (12 ÷ срок распродажи)
```

Возвращённый пробник считается потерянным вместе с содержимым. Количество
пробников дробное и округляется только при выводе.

Значения по умолчанию — ориентировочные, под Xerjoff Alexandria II 100 мл;
подставьте свои закупку, комиссии каналов и цены атомайзеров.
