# Экономика распива

Веб-калькулятор юнит-экономики для продажи парфюмерии на распив в Словакии:
считает в евро, что останется в кармане, если разлить дорогой флакон на
пробники 2 / 5 / 10 мл.

Открывается двойным кликом по `index.html` — одна страница, без сборки,
зависимостей и бэкенда. Введённые параметры сохраняются в браузере.

## Что считает

- **Себестоимость миллилитра** с учётом доставки и потерь при разливе.
- **Полная себестоимость пробника** каждого размера: жидкость, атомайзер,
  расходники, труд, отправка и реклама в пересчёте на штуку.
- **Минимальная цена** — точка нуля с учётом комиссий площадки, эквайринга,
  DPH и возвратов.
- **Ценовая сетка** — цена при наценке ×1,5 / ×1,75 / ×2 / ×2,5 и при целевой
  марже 35%. Клик по цене подставляет её в расчёт.
- **Флакон в разрезе** — как объём делится между размерами и на каком проценте
  объёма флакон полностью отбивается.
- **Сценарии по скорости продаж** — срок распродажи, прибыль в месяц, остаток
  после фиксированных расходов и годовой возврат с учётом оборачиваемости.
- **Чувствительность** — рост закупки, падение цен, удвоение возвратов, смена
  режима DPH и неполная распродажа флакона.
- **Распив против продажи флакона целиком** и вердикт с разбором слабых мест.

## Словацкая налоговая модель

| Параметр | Как учитывается |
|---|---|
| Режим DPH | Переключатель. «Не плательщик» — DPH сидит в закупке и не возвращается. «Плательщик» — DPH вычитается из цены продажи, но закупка, атомайзеры и отправка считаются без неё |
| Ставка DPH | По умолчанию 23% |
| Daň z príjmu | По умолчанию 15% (živnosť), берётся с прибыли, а не с выручки |
| Фиксированные расходы | Odvody и подписки, € в месяц — вычитаются в сценариях по скорости продаж |

Порог обязательной регистрации плательщиком DPH — 50 000 € оборота за
календарный год; при выходе за него калькулятор подсказывает переключить режим.
Ставки и пороги меняются — перед тем как считать расчёт планом, сверьтесь
с finančná správa или со своим účtovník.

## Модель расчёта

```
полезный объём      = объём × (1 − потери)
себестоимость 1 мл  = (закупка + доставка) ÷ полезный объём
себестоимость шт    = жидкость + атомайзер + расходники + труд
                      + (отправка + реклама) ÷ пробников в заказе
прибыль шт          = цена ÷ (1 + DPH) × (1 − комиссии − эквайринг) × (1 − возвраты)
                      − себестоимость шт
вклад в окупаемость = прибыль шт + стоимость жидкости
штук до нуля        = стоимость флакона ÷ средний вклад
прибыль с флакона   = (вклад × штук − стоимость флакона) × (1 − daň z príjmu)
годовой возврат     = возврат за флакон × (12 ÷ срок распродажи)
```

Возвращённый пробник считается потерянным вместе с содержимым. Собственное
время и реклама в обоих режимах DPH идут как есть. Количество пробников дробное
и округляется только при выводе.

Значения по умолчанию — ориентировочные, под Xerjoff Alexandria II 100 мл;
подставьте свои закупку, комиссии каналов и цены атомайзеров.
