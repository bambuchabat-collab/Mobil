Ты аналитик лотерей и статистик. Подготовь ставку на ближайший тираж EXTRA VÝPLATA (TIPOS, Словакия: 6 чисел из 27 + 1 доп. число из 7, 1,50 € за поле, до 8 полей на купоне).

1. Данные. Скачай все тиражи с первого (25.03.2024) по последний с tipos.sk: список дат через /Millennium.CiselneLoterie/ExtraVyplata/GetZrebovania (POST Rok, Mesiac), результаты через /Millennium.CiselneLoterie/ExtraVyplata/GetForDate (POST datumZrebovania). Сверь частоты с официальной статистикой /Millennium.CiselneLoterie/extravyplata/GetStatsV1. Возьми срок приёма ставок и время тиража со страницы лотереи.

2. Частоты. Для каждого основного числа и доп. числа: сколько раз выпало за всё время, за последние 52 и 26 тиражей, ожидание и σ. Назови самые частые и самые редкие.

3. Случайность. Методом Монте-Карло (20 000 честных историй той же длины) посчитай p-значения: хи-квадрат по основным и доп. числам, максимум и минимум частот, устойчивость «горячих» чисел между первой и второй половиной истории, повтор доп. числа с прошлым тиражом (перестановочный тест), суммы, чёт/нечёт, малые/большие, соседние числа против точной теории. Разбей подозрительные эффекты по периодам.

4. Формулы. Построй не меньше 10 формул предсказания (горячие за разные окна, холодные, давно не выпадавшие, повтор прошлого, пары, марковская, смешанная). Прогони walk-forward бэктест: каждый тираж предсказывается только по прошлым. Сравни со случайным выбором, поправь на множественные проверки и покажи результат по периодам, особенно за последние месяцы.

5. Деньги. Точные шансы всех уровней (6+1 … 3+0), средние призы за год, реальная доля выплат (выплаты / ставки), ожидаемый результат на поле.

6. Купон. Для 1–24 полей найди набор, который максимизирует шанс хотя бы одного выигрыша (3+ совпадения в любом поле), точным перебором всех 296 010 комбинаций. Сравни со случайными полями той же цены. Первое поле = числа лучшей формулы, доп. числа разнеси по всем 7 значениям, избегай «узоров».

7. Ответ. Скажи прямо: сколько полей брать, какие билеты ставить сегодня, какие числа выпадали чаще всего, и есть ли у формулы реальное преимущество над случайностью. Не обещай выигрыш.
