# S2 — предрегистрация (теория информации, алгоритмическая сложность)

Записано: 2026-11-27T20:39:57Z (UTC), до любого расчёта по исходам тиражей.
(До записи смотрел только структуру файлов: число тиражей, N = 33, K = 7, extra 1–6, VAN N = 22, K = 11, даты по возрастанию.)

## Игра

**Euromilióny (EM)**, все три формулы. Причина: 1 242 тиража (1 212 в проверке против 385 у VAN) — в ~3 раза больше
данных и мощности; кроме того, универсальным предсказателям (CTW, LZ) нужны длинные последовательности: у EM их 33 по
1 242 символа. Дата `date` формулами не используется (универсальный предсказатель работает только по последовательности).

## Представление данных

Для числа i ∈ {1..33}: бинарная последовательность x_i(s) = 1, если i ∈ main(s), иначе 0, s = 0..t−1 (только `past`).
Базовая частота K/N = 7/33. Каждая формула даёт для каждого i прогнозную вероятность p_i = P(x_i(t) = 1 | past) и
выбирает T = 7 чисел с наибольшим p_i. Ничьи (равные p_i с точностью 1e-12) разбиваются фиксированным ключом:
`np.random.default_rng(int(date.replace('-',''))).random(33)` (меньше ключ — раньше), это не зависит от исходов.

## Общие элементы

- KT-оценка (Кричевский–Трофимов) в узле со счётчиками (a нулей, b единиц):
  log Pe(a,b) = lgamma(a+½) + lgamma(b+½) − 2·lgamma(½) − lgamma(a+b+1); P(1) = (b+½)/(a+b+1).
- CTW (context-tree weighting, Willems–Shtarkov–Tjalkens 1995), глубина **D = 8**, контекст = (x(s−1), …, x(s−8)),
  до начала истории контекст дополняется нулями. Узел глубины < D: Pw = ½·Pe + ½·Pw(child0)·Pw(child1); лист: Pw = Pe.
  Прогноз: P(1) = Pw_root(после добавления 1) / [Pw_root(после 1) + Pw_root(после 0)]. Состояние CTW зависит только от
  счётчиков узлов, поэтому пакетное обновление точно.
- Код длины (prequential): L_m(t) = Σ_{s<t} Σ_i −log2 P_m(x_i(s) | тиражи до s), вероятности для тиража s считаются
  только по тиражам до s.

## Формулы (все параметры зафиксированы здесь; подбор не делается вообще)

- **F1 — CTW по каждому числу.** Для каждого из 33 чисел своё контекстное дерево CTW глубины 8 с KT на его бинарной
  последовательности. Прогноз = 7 чисел с максимальной CTW-вероятностью P(x_i(t)=1 | x_i(0..t−1)).
  Смысл: байесовская смесь по всем деревьям контекстов (переменный порядок Маркова ≤ 8) с весом 2^(−длина описания
  дерева) — универсальный предсказатель для любого стационарного источника конечной памяти ≤ 8, отдельно для каждого шара.
- **F2 — LZ78-предсказатель по каждому числу (Feder–Merhav–Gutman 1992).** Для каждого числа — дерево
  инкрементального разбора LZ78 его последовательности. Указатель cur стартует в корне; в узле cur счётчики n0, n1 —
  сколько раз из cur шли по символу 0/1. P(1) = (n1+½)/(n0+n1+1). После символа x: n_x(cur) += 1; если ребёнок x есть —
  cur := ребёнок, иначе создаётся ребёнок x (конец фразы) и cur := корень. Прогноз = 7 чисел с максимальным P(1).
- **F3 — выбор модели по MDL (prequential) из заранее фиксированного набора.**
  M0: i.i.d. Bernoulli(7/33) для каждого числа (честная лотерея, без обучения);
  M1: KT-Bernoulli для каждого числа (частота, 1 параметр на число);
  M2: общий (pooled) CTW глубины 8 — одно дерево на все 33 числа (общая структура памяти, напр. «выпало прошлый раз»),
      обновляется пакетом всех 33 символов после каждого тиража;
  M3: CTW по каждому числу (= F1);
  M4: LZ78 по каждому числу (= F2).
  Перед тиражом t выбирается модель с минимальной L_m(t) по всем прошлым тиражам (при равенстве — меньший индекс m);
  прогноз = 7 чисел с наибольшим p_i выбранной модели (у M0 все p_i равны — выбор решает фиксированный ключ ничьих).

Главная метрика — `p_upper` из `harness2.evaluate(f, 'EM', name)` (walk-forward от тиража 30). Сырые p, без поправок.
Предсказание на 28.11.2026 — по F1 по всей истории EM (1 242 тиража).

## Вторичный описательный анализ (не формула, в Холм не идёт): оценка энтропийной скорости

E: на всей истории EM (и отдельно VAN, N = 22, K = 11) считаю длину кода L_m для M1–M4 и сравниваю с i.i.d.-максимумом
L_M0 = n·N·h(K/N) бит (h — двоичная энтропия; для EM h(7/33) ≈ 0,7455 бит/символ, для VAN 1 бит/символ).
Статистика G_m = L_M0 − L_m («выигрыш сжатия», бит). H0: тиражи — независимые равновероятные K-подмножества.
Нулевое распределение G_m — Монте-Карло, 200 симуляций, seed = 2811 (EM) и 2812 (VAN). p_E(m) = (1 + #{G_sim ≥ G_obs}) / 201.
Энтропийная скорость ниже i.i.d.-максимума ⇔ G_m значимо больше нуля относительно нулевого распределения.
Также сообщаю энтропийную скорость CTW-оценки в бит/символ и бит/тираж против log2 C(N,K) (EM: log2 C(33,7) ≈ 22,02 бит).

## Ожидание

Если розыгрыш честный, G_m < 0 (универсальные коды платят «штраф обучения» ~½·log2 n на параметр), M0 выигрывает MDL
почти всегда, и F1–F3 дают p_upper ~ U(0,1). Формула «работает», только если p_upper мал и G_m > 0 со значимым p_E.
