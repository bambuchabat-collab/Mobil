## Игра: Euromilióny (EM), все три формулы

Почему EM, а не VAN:
1. Все три метода обучаются на истории (веса экспертов, библиотека аналогов, обучающая выборка сети). У EM 1 242 тиража против 415 у VAN — втрое больше данных для обучения и 1 212 оценочных тиражей против 385.
2. Мощность: при T=K=7, N=33 стандартное отклонение числа совпадений ≈ 0,975, ошибка среднего за 1 212 тиражей ≈ 0,028 (≈1,9 % от ожидаемых 1,485). Для VAN ≈ 0,061 при 5,5 (≈1,1 %) — но на втрое меньшей истории методы почти не успеют обучиться.
3. Новизна: в FINDINGS.md EM не проверялась вообще (Loto 5 z 35, Extra výplata, VAN). Hedge и аналоги проверялись только на Loto 5 z 35 / Extra výplata; здесь новое — большая библиотека из 26 экспертов (включая порядок выпадения, день недели, месяц, пары, Маркова), анализ задержек (delay embedding Лоренца/Такенса) и перестановочно-симметричная нейросеть со списочной (softmax) функцией потерь.

## Общие обозначения

- `past` — тиражи строго до оцениваемого (индексы 0..t−1), `date` — дата оцениваемого тиража.
- X[u] ∈ {0,1}^33 — индикатор чисел тиража u. N = 33 (берётся из данных как в harness), K = T = 7.
- cnt_W(i) = Σ_{u=max(0,t−W)}^{t−1} X[u,i]; W = all — вся история.
- gap(i) = t−1 − (последний u, где i выпало); если не выпадало — gap = t.
- Разрыв ничьих: ко всем счётам прибавляется ε·π_i, π — фиксированная случайная перестановка 0..32 (numpy seed 2811), ε = 1e−9. Числа выбираются как 7 с наибольшим счётом.
- Подбор параметров: никакого. Все параметры заданы ниже заранее, первые 30 тиражей используются только как стартовая история (оценка harness начинается с тиража 30).
- Главная метрика — `p_upper` из `harness2.evaluate`; поправку на множественность не делаю.

## F1 — Hedge (экспоненциальные веса) над библиотекой из 26 экспертов

Каждый эксперт e по past (и date) даёт счёт s_e(i) и свой набор P_e = top-7.
Эксперты:
- E1–E6 «горячие»: cnt_W, W ∈ {5, 10, 20, 50, 100, all}.
- E7–E9 «холодные»: −cnt_W, W ∈ {10, 50, all}.
- E10 «давно не было»: gap(i).
- E11 «относительная задержка»: gap(i)·(cnt_all(i)+1)/(t+1).
- E12 повтор прошлого тиража: X[t−1,i] + 0.01·cnt_50(i).
- E13 повтор позапрошлого: X[t−2,i] + 0.01·cnt_50(i).
- E14 «не повтор»: −X[t−1,i] + 0.01·cnt_50(i).
- E15 соседи ±1 прошлого тиража: Σ_{j∈t−1} 1[|i−j|=1] + 0.01·cnt_50(i).
- E16 соседи ±2: Σ_{j∈t−1} 1[|i−j|=2] + 0.01·cnt_50(i).
- E17 «ранние шары»: сколько раз i было на позициях 1–3 порядка выпадения за последние 100 тиражей.
- E18 «поздние шары»: то же для позиций 5–7.
- E19 день недели: cnt по последним 50 прошлым тиражам с тем же днём недели, что у `date`.
- E20 месяц: cnt по всем прошлым тиражам того же календарного месяца, что у `date`.
- E21 зеркало: X[t−1, 34−i] + 0.01·cnt_50(i).
- E22 пары: Σ_{j∈t−1, j≠i} C[i,j], C — число совместных выпадений за всю прошлую историю.
- E23 Марков: Σ_{j∈t−1} F[j,i], F[j,i] = #{u: j ∈ тираж u−1 и i ∈ тираж u} в прошлом.
- E24 EMA с полураспадом 10 тиражей: Σ_u 0.5^{(t−1−u)/10} X[u,i].
- E25 EMA с полураспадом 100.
- E26 случайный: перестановка с seed = int(date без дефисов).
Отсутствующие тиражи (t−2 < 0 и т. п.) — нули.

Hedge: потеря эксперта на тираже s: ℓ_{e,s} = 1 − |P_e(s) ∩ draw_s|/7, где P_e(s) построен только по тиражам < s. Накопленная L_{e,t} = Σ_{s=1}^{t−1} ℓ_{e,s}. Вес w_e ∝ exp(−η_t (L_{e,t} − min_e L_{e,t})), η_t = sqrt(8 ln 26 / max(1, t−1)) (anytime Hedge).
Прогноз: S(i) = Σ_e w_e·1[i ∈ P_e(t)] + ε·π_i; набор = top-7 по S.

## F2 — аналоговый прогноз (k ближайших соседей) в пространстве задержек

Состояние перед тиражом s: z_s = [X[s−1], X[s−2], X[s−3]] ∈ {0,1}^99 (вложение задержек, m = 3), определено при s ≥ 3.
Для оцениваемого t: z_t из последних трёх прошлых тиражей. Кандидаты s ∈ {3, …, t−1} (у них известен «следующий» тираж X[s]).
Расстояние Хэмминга d(z_t, z_s) = Σ|z_t − z_s|. Берём k = min(30, число кандидатов) ближайших; при равных расстояниях предпочитаем более поздние s.
Счёт: S(i) = Σ_{соседи s} X[s,i] + ε·π_i; набор = top-7.

## F3 — маленькая нейросеть (numpy MLP), перестановочно-симметричная, обучение walk-forward

Признаки числа i перед тиражом t (только по прошлому), 17 штук:
1–10: X[t−1,i], …, X[t−10,i] (нули, если тиража нет);
11: cnt_30(i)/min(30,t); 12: cnt_100(i)/min(100,t); 13: cnt_all(i)/t;
14: log(1+gap(i)); 15: число соседей ±1 среди чисел прошлого тиража;
16: позиция в порядке выпадения прошлого тиража: 1 − pos/7 (pos = 0..6), если i там было, иначе 0;
17: (i − 17)/16 (идентичность числа как скаляр).
Признаки стандартизуются по среднему/ст. отклонению обучающей выборки.

Сеть (общая для всех 33 чисел): 17 → 16 (tanh) → 1 логит; softmax по 33 числам одного тиража; потеря — перекрёстная энтропия с целевым распределением X[s]/7 + L2 1e−4 на матрицы весов. Инициализация Глорот, seed = 2811 + t_refit. Adam, lr 0.005, β = (0.9, 0.999), полный батч.
Обучающие тиражи для переобучения в момент t: s = 10, …, t−1. Ранняя остановка: последние 20 % этих тиражей (по времени, не меньше 4) — валидация, остальные — обучение; максимум 300 эпох, терпение 20 эпох, возвращаются лучшие по валидации веса. Только прошлые тиражи.
Переобучение с нуля при t = 30, 50, 70, … (каждые 20 тиражей, (t−30) mod 20 = 0); между переобучениями используется последняя модель на свежих признаках. Для прогноза на 28.11 (t = 1242) действует то же правило (модель от t = 1230).
Набор = top-7 по логитам (+ ε·π_i).
