## Идея (криптоаналитик смотрит на тиражи как на выход шифра/генератора)

Если розыгрыш делает программа (генератор псевдослучайных чисел), то её выход имеет малую **линейную сложность**
в каком-то представлении: LFSR, xorshift, Tausworthe, Mersenne Twister — линейны над GF(2); LCG и лагированный
Фибоначчи (x_n = x_{n−j} ± x_{n−k} mod p) — линейные рекуррентности над Z_p. Алгоритм Берлекэмпа–Мэсси (BM) находит
**кратчайшую** линейную рекуррентность (LFSR), порождающую всю наблюдённую последовательность, за O(n²); если она
короткая (L < n/2), то её продолжение предсказывает будущее. Для истинно случайной последовательности L ≈ n/2 и
предсказание LFSR — монетка. Три формулы = BM-атака в трёх представлениях тиража (поток битов по числу; поток выходов
генератора «выбор из оставшихся» над GF(p); те же выходы в двоичном виде над GF(2)). Плюс диагностика: батарея тестов
NIST SP 800-22 и полный перебор состояний распространённых 32-битных LCG.

BM во всех формулах работает **онлайн** (последовательно по символам, состояние зависит только от уже поданных символов
`past`; кэш состояния между вызовами проверяет, что `past` продолжает уже поданный префикс, иначе пересчёт с нуля).
`date` формулы не используют.

## Выбор игр (обе)

- **F1 → VAN.** Поток «число x выпало / нет» в VAN — сбалансированные биты (P = 11/22 = ½), ровно тот случай, для
  которого построены BM-атака на LFSR и тесты NIST. VAN — основная игра пользователя, тираж в сб 28.11 есть. Один тираж
  VAN с порядком (11 из 22, ~44,7 бит) однозначно определяет 32-битное состояние генератора (нужно для D2).
- **F2, F3 → EM.** Самая длинная история: 1 242 тиража × 7 упорядоченных шаров = 8 694 выхода «генератора»
  (~52 000 бит в F3). Чтобы BM восстановил рекуррентность длины L, нужно 2L символов: только у EM хватает бит
  (52 164 > 2·19 937) даже на линейную сложность Mersenne Twister. 1 212 оценочных тиражей — втрое больше мощности.

## Формулы

Общее: **код Лемера** упорядоченного тиража (order) — r_k = индекс (с 0) шара order[k] в отсортированном списке ещё
не вытянутых шаров, k = 1..K; r_k ∈ [0, N−k]. Это ровно последовательность вызовов rand(N−k+1) в самой распространённой
программной схеме «вытащить шар из оставшихся». Декодирование предсказанных значений v_1..v_T: remaining = [1..N] по
возрастанию; для k: ball_k = remaining.pop(v_k mod len(remaining)) — всегда T различных допустимых чисел.

- **F1 (главная, VAN) — BM над GF(2) по потокам чисел.** Для каждого x = 1..22 поток s_x(j) = 1[x ∈ main_j] по всем
  прошлым тиражам j (старые первыми). BM даёт связной многочлен C_x(D) = 1 + Σ c_i D^i и сложность L_x. Прогноз
  следующего бита ŝ_x = Σ_{i=1..L_x} c_i s_x(n−i) mod 2 (n = len(past)). Уверенность κ_x = n − 2·L_x (сколько бит LFSR
  воспроизвёл сверх необходимых для его определения). Билет = 11 чисел с наибольшим ключом (ŝ_x, κ_x, −τ_x), где
  τ = np.random.default_rng(2811).permutation(22) — фиксированный порядок разбиения ничьих (τ_x = позиция x−1).
- **F2 (EM) — BM над GF(37) по потоку кодов Лемера** (восстановление LCG / лагированного Фибоначчи по модулю p).
  Поток = r_1..r_7 всех прошлых тиражей подряд (старые первыми), элементы GF(37) (37 — наименьшее простое > 33).
  BM (полная история, онлайн) → рекуррентность длины L; продолжение на 7 символов:
  v = −Σ_{i=1..L} c_i v(n−i) mod 37; декодирование как выше (v_k mod (34−k)). LCG x' = a·x + c mod 37 имеет L ≤ 2,
  генератор Кнута (24, 55) — L = 55; BM находит любую такую рекуррентность за 2L символов.
- **F3 (EM) — BM над GF(2) по двоичному потоку кодов Лемера** (атака на GF(2)-линейный генератор сырых бит:
  LFSR, xorshift, Tausworthe/taus88, WELL, MT19937). Каждый r_k записывается 6 битами (старший первым), 42 бита на
  тираж, поток по всей истории. BM (онлайн) → LFSR; продолжение на 42 бита → 7 шестибитных чисел v_k ∈ [0, 63];
  декодирование как выше (v_k mod (34−k)).

## Диагностика (не формулы, в Холм не идут, сообщаю сырые p)

- **D0 (целостность).** Доля тиражей, где order = sorted(main) (признак записей без порядка), VAN и EM; распределение
  дней недели EM (есть ли тираж в субботу). Только описательно, ничего не меняет в формулах.
- **D1 (батарея NIST SP 800-22, формулы из стандарта, igamc/erfc реализованы сами).** Потоки:
  (a) VAN_set: комбинаторный ранг тиража R = Σ_i C(c_i − 1, i) по отсортированным числам c_1 < … < c_11,
      R ∈ [0, C(22,11)); если R < 2^19 — 19 бит (старший первым), иначе тираж пропускается (несмещённые биты при H0);
  (b) EM_set: то же, C(33,7) = 4 272 048, берётся R < 2^22 → 22 бита;
  (c) VAN_ord: ранг упорядоченного тиража (смешанная система по кодам Лемера, Горнер R = R·(N−k+1) + r_k),
      R ∈ [0, 22!/11!), берётся R < 2^44 → 44 бита;  (d) EM_ord: [0, 33!/26!), R < 2^34 → 34 бита.
  Тесты на (a)–(d): Frequency; Block Frequency (M = 128); Runs; Serial (m = 4, оба p); Approximate Entropy (m = 4);
  Cumulative Sums (вперёд и назад); Linear Complexity — точный двусторонний тест сложности L всей последовательности
  по распределению Рюппеля (P(L) = 2^{2L−n−1} при 1 ≤ L ≤ n/2, 2^{n−2L} при L > n/2). Итого 9 p на поток.
  (e) VAN по числам: 22 потока по 415 бит: Frequency, Runs, Serial (m = 3, оба p), ApEn (m = 2), CuSum (вперёд),
      Linear Complexity (точный). 7 × 22 = 154 p.
  Сводка: число p < 0,01 против ожидаемого, минимальный p, биномиальный p для числа p < 0,01.
- **D2 (полный перебор состояния 32-битных LCG, «восстановление состояния по последовательным шарам»).**
  VAN, тиражи с индексами 0–4 (в пределах первых 30). Генераторы (x ← a·x + c mod m, выход из нового x):
  G1 Borland Delphi/Turbo Pascal a = 134775813, c = 1, m = 2^32, rand(n) = (x·n) >> 32;
  G2 Microsoft C a = 214013, c = 2531011, m = 2^32, o = (x >> 16) & 0x7FFF: rand(n) = o mod n | (o·n) >> 15;
  G3a ANSI/glibc TYPE_0 a = 1103515245, c = 12345, m = 2^31, o = x: rand(n) = x mod n | (x·n) >> 31;
  G3b то же, o = (x >> 16) & 0x7FFF: o mod n | (o·n) >> 15;
  G4 Numerical Recipes a = 1664525, c = 1013904223, m = 2^32: x mod n | (x·n) >> 32;
  G5 MINSTD a = 16807 и G6 a = 48271, c = 0, m = 2^31 − 1: x mod n | floor(x·n / m).  Итого 13 вариантов.
  Процедуры вытаскивания: P1 pop(rand(len)) из отсортированного остатка; P2 a[j] с заменой на последний;
  P3 rand(22)+1 с отбрасыванием повторов; P4 частичный Фишер–Йейтс вперёд (j = k + rand(22−k), swap, шар = a[k]);
  P5 Фишер–Йейтс назад (i = 21−k, j = rand(i+1), swap, шар = a[i]).
  Перебираются ВСЕ состояния, дающие первый шар (≈ 1–2·10^8 на вариант), затем фильтр по шарам 2..11.
  При H0 ложное совпадение на (вариант, процедура, тираж) ≤ 2^32·11!/22! ≈ 1,5·10^-4. Гипотеза генератора считается
  подтверждённой, если состояние найдено хотя бы для 2 из 5 тиражей. Положительный контроль: для каждого из 13
  вариантов синтетический тираж из случайного состояния (seed 2811) по процедуре P_(i mod 5 + 1) — поиск обязан его найти.
  Что D2 не покрывает: 48-битный Java Random, MT19937/PCG/xoshiro с полным состоянием, 32-битный лагированный
  Фибоначчи glibc random(), аппаратные ГСЧ, шаровые машины.
