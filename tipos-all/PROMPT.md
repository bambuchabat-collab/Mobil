Ты аналитик лотерей и статистик. Разбери все числовые лотереи TIPOS (Словакия), кроме Keno: LOTO (6 из 49, два тяга), LOTO 5 z 35, EUROJACKPOT (5 из 50 + 2 из 12), EUROMILIÓNY (7 из 33 + 1 из 6), VŠETKO ALEBO NIČ (11 из 22), EXTRA VÝPLATA (6 из 27 + 1 из 7) и дополнительные игры JOKER.

1. Данные. Для каждой игры скачай историю тиражей с tipos.sk: даты через /Millennium.CiselneLoterie/<Игра>/GetZrebovania (POST Rok, Mesiac), результаты через /Millennium.CiselneLoterie/<Игра>/GetForDate (POST datumZrebovania). Возьми текущие джекпоты, цены и сроки приёма ставок со страниц игр. Правила и формулы призов проверь по игровому плану (herný plán).

2. Та же работа, что для Extra výplata, для каждой игры: частоты чисел, самые частые и редкие, хи-квадрат и максимум частоты (p методом Монте-Карло), walk-forward бэктест формул (горячие за всё время, 52 и 20 тиражей, холодные, давно не выпадавшие, повтор прошлого, итоговая смешанная формула) с разбивкой по периодам. Для Joker проверь равномерность цифр на каждой позиции.

3. Деньги. Для каждой игры посчитай ожидаемый возврат на 1 € ставки при сегодняшних джекпотах: точные вероятности всех уровней, средние призы за последние 104 тиража, ожидаемый размер джекпота к следующему тиражу и вероятность его дележа (по числу проданных ставок).

4. Лазейка. Ищи только законные структурные преимущества: накопившиеся джекпоты при фиксированном шансе, фиксированные призы, превышающие честную цену, правила дележа и потолки. Найди игру, где ожидаемый возврат сейчас выше ставки, и посчитай порог окупаемости.

5. Ответ. Дай 3 билета Extra výplata на сегодня по лучшей формуле, выбери один билет из любой игры TIPOS и объясни почему. Честно скажи, есть ли у формул преимущество над случайностью и насколько реален выигрыш. Не обещай выигрыш.
