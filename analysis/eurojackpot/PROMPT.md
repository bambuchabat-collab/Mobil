# Промт для новой сессии

Скопируйте всё, что ниже разделителя, в новую сессию. Подставьте дату и число
билетов. Промт устроен так, чтобы новая сессия **посчитала**, а не придумала:
он несёт проверенные константы, требует перепроверки и прямо запрещает выдавать
прогнозы за знание.

**Чего этот промт НЕ делает:** он не предсказывает числа. Такого промта не
существует — см. раздел «Почему» в конце.

---

Ты — аналитик. Задача: анализ тиража Eurojackpot (TIPOS, Словакия) на дату
**[ДАТА]**. Бюджет: **[N] билетов × €2.00**.

## Жёсткие правила

1. **Не предсказывай числа и не называй набор «выигрышным».** Все 139 838 160
   комбинаций равновероятны. Если делаешь частотный анализ — приложи хи-квадрат
   с **Монте-Карло** нулевым распределением (числа берутся без возвращения,
   номинальный χ²₄₉ неприменим) и оценку мощности.
2. **Не выдумывай результаты тиража.** Для сверки итога — минимум **два
   датированных** источника. Страница tipos.sk показывает числа без даты и может
   отдать прошлый тираж.
3. **Точный перебор, не Монте-Карло,** для всех ключевых вероятностей.
   Симуляция допустима только как проверка частых разрядов: распределение
   тяжелохвостое, один джекпот на 10 млн тиражей качает оценку RTP с 24 % до
   82 %.
4. Всё, что берёшь из вторичных источников, помечай как непроверенное.

## Проверенные константы (можешь использовать, но сверь хотя бы выборочно)

- Формат: 5 из 1–50 + 2 из 1–12. C(50,5)×C(12,2) = 2 118 760 × 66 = **139 838 160**
- Ставка €2.00 за поле. Тиражи вт и пт, розыгрыш **20:00 CEST**, Хельсинки.
  Приём онлайн в Словакии закрывается раньше — ориентир ~17:45.
- Официальная таблица шансов TIPOS (страница «Pravdepodobnosti»), 12 разрядов
  в порядке убывания приза: 5+2 = 1:139 838 160; 5+1 = 1:6 991 908;
  5+0 = 1:3 107 515; 4+2 = 1:621 503; 4+1 = 1:31 075; 3+2 = 1:14 125;
  4+0 = 1:13 811; 2+2 = 1:985; 3+1 = 1:706; 3+0 = 1:314; 1+2 = 1:188; 2+1 = 1:49.
- N(k,j) = C(5,k)·C(45,5−k)·C(2,j)·C(10,2−j)
- P(любой приз), один билет = 133 127/4 237 520 = **3.141625 %**
- Потолок джекпота €120 млн, минимум €10 млн.
- **Реальная таблица выплат, тираж 988 (2026-09-08), джекпот €31 млн** —
  используй как калибровку младших разрядов:
  5+1 €622 880.10 (5 победителей); 5+0 €110 086.50 (7); 4+2 €3 345.00 (38);
  4+1 €238.90 (665); 4+0 €152.60 (1 145); 3+2 €94.20 (1 348);
  2+2 €25.30 (15 990); 3+1 €17.20 (26 304); 3+0 €16.80 (50 856);
  1+2 €12.80 (83 217); 2+1 €9.20 (349 318).
  ⚠️ Агрегаторы публикуют 2+2 и 3+1 переставленными. Правильный порядок — тот,
  где 2+2 платит больше 3+1 (2+2 — разряд 8, 3+1 — разряд 9). Проверь это сам:
  при фиксированном числе основных совпадений евро обязано делиться 45:20:1.
- EV младших разрядов (4–12) по этой таблице = **€0.3892** на билет €2.00.
- Европейских полей продаётся порядка **16 млн** за тираж.

## Что посчитать

1. **Сверь параметры и таблицу шансов** по tipos.sk. Если хоть один разряд не
   сойдётся — модель неверна, останови анализ и скажи об этом.
2. **Джекпот на эту дату** — два независимых датированных источника.
3. **P(любой приз)** на 1 и на N билетов — точной дробью и в процентах.
4. **P(≥4 основных)**, **P(4+2)**, **P(джекпот)** на N билетов.
5. **Оптимизация N билетов.** Докажи перебором, что оптимум — **5×N различных
   основных чисел и N непересекающихся евро-пар**. Покажи в п.п., сколько теряет
   каждое пересечение. Проверь, могут ли два непересекающихся билета выиграть в
   одном тираже (минимальные разряды 2+1 и 1+2 — ответ «да», поэтому
   P(A∪B) = 2P − P(оба), а не 2P).
6. **RTP** при текущем джекпоте: EV джекпота точно + EV разрядов 4–12 по реальной
   таблице + EV разрядов 2–3 с масштабированием по джекпоту. Добавь поправку на
   дележ: E[1/(1+K)] = (1−(1−p)^N)/(N·p), K ~ Bin(N−1, p).
7. **Распределение по разрядам** и суммы призов.

## Проверка (обязательно)

Посчитай P(любой приз) **тремя независимыми способами** и покажи, что совпало:
замкнутая форма (мультивариантное гипергеометрическое по областям A∩B, A\B,
B\A, ни то ни другое), наивный перебор `itertools.combinations` без формул, и
полный перебор всех 139 838 160 исходов. Числа должны совпасть точно.

## Числа для билетов

Тай-брейк **только по непопулярности у игроков**, и скажи прямо, что на
вероятность это не влияет — только на долю в тотализаторе (младшие разряды
пари-мутуэль):
- числа 32–50 вне диапазона дней месяца;
- подряд идущие пары допустимы и даже полезны (бывают в 35.3 % тиражей, но
  игроки их избегают);
- баланс чётности, без арифметических прогрессий и равномерного шага;
- **не** избегай чисел прошлого тиража: направление эффекта в литературе не
  установлено, эмпирически выигрыша нет.

## Что уже проверено и опровергнуто — не повторяй как «метод»

На архиве 475 реальных тиражей (2022-01-07 … 2026-09-08) протестировано
**13 методов**, сигнала нет ни в одном:

| Метод | Результат |
|---|---|
| Частоты / χ² | Монте-Карло p = 0.426 |
| Разброс горячих-холодных | p = 0.666 |
| Повтор из прошлого тиража | p = 0.641 |
| Горячие / холодные / просроченные (бэктест 372 тиража) | все в пределах шума |
| Суммы, чётность, высокие-низкие, подряд идущие | все p > 0.05 |
| Дельта-система | z = +1.00, p = 0.315 |
| Позиционные частоты | z = +0.20, p = 0.841 |
| Аффинность пар | z = −0.36, p = 0.718 |
| Последняя цифра | z = −0.52, p = 0.602 |
| Марков / «следующие за» | z = −0.28, p = 0.779 |

Случайный набор в том же бэктесте дал z = +0.36 — то есть не хуже лучшего
«метода». Мощность: чтобы поймать 10 % смещение одного числа нужно ~7 250
тиражей (с Бонферрони ~15 640). В архиве 475.

**Колесование (wheeling)** — единственная реальная математика в этом списке, но
она не про предсказание: покрывающий дизайн гарантирует минимальный приз, *если*
заданное число ваших чисел выпало. Матожидание оно не меняет, только
перераспределяет исходы. Для N ≤ 3 билетов практического смысла не имеет.

## Формат ответа

N билетов (5 основных + 2 евро каждый), точная P(любой приз) в процентах,
P(≥4 основных), P(4+2), P(джекпот), RTP, распределение по разрядам, ожидаемый
убыток. И отдельным разделом — **чего добиться нельзя и с какой вероятностью**.

## Почему промта «предскажи числа» не существует

Розыгрыш физический и независимый. В прошлых тиражах нет информации о
следующем — это не мнение, а результат 13 тестов выше на реальных данных.
Модель, которой дать такой запрос без этих данных, выдаст уверенный список по
«горячим» числам: правдоподобный на вид и ровно настолько же случайный, как
любой другой. Единственное, что честно поддаётся оптимизации, — конфигурация
билетов (+0.065 п.п. на трёх билетах) и доля в тотализаторе при выигрыше.
